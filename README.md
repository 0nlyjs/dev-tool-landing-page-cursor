# Cursor Landing Page Clone

A pixel-perfect, desktop-only recreation of the [Cursor](https://cursor.com/)) website using **only HTML & CSS**.

**🔗 Live Demo:** [https://0nlyjs.github.io/dev-tool-landing-page-cursor/]

## 🛠 Project Details
* **Tech Stack:** Pure HTML5 & CSS3 (No JS, No Frameworks).
* **Fonts Used:** Helvetica Neue, Courier, monospace
* **Theme:** Dark Mode (#14120b,#1B1913).

## ✅ Recreated Sections
1. Navigation & Hero
2. Trusted By & Feature Blocks
3. Feature Cards & Testimonials
4. Use Cases & Changelog
5. Team, CTA & Footer
